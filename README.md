# SpillIt 👀

SpillIt is a full-stack anonymous messaging platform where users can receive honest feedback and messages without revealing the sender's identity.

## 🚀 Features

- 🔐 Authentication using NextAuth
- 💬 Send and receive anonymous messages
- 🤖 AI-powered message suggestions
- 📊 User dashboard to manage messages
- 🔁 Toggle to accept/reject messages
- 🔗 Unique public profile link for each user

## 🛠 Tech Stack

- **Frontend:** Next.js (App Router), React, Tailwind CSS, shadcn/ui
- **Backend:** Next.js API Routes
- **Database:** MongoDB
- **Authentication:** NextAuth
- **AI Integration:** OpenRouter (Mistral model)
